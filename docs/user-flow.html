이번 수정 요약
· 페이지1 문구 변경 (72시간 메캠팅 인트로)
· 페이지3 학과에 의예과 추가 + 직접입력란 추가
· 페이지2·4·5 및 이후 화면은 기존 유지
· 미션3 변경: "학과교류주점에 방문해 함께 사진을 찍고, 상품을 받으세요!"
· 미션 안내에 "완료한 미션은 가천대 메디컬캠퍼스 인스타로 DM을 보내 인증해주세요!" 문구 추가
· 미션 인증/체크는 관리자 페이지에 넣지 않음 — 운영진이 인스타 DM으로 직접 확인
· 온라인 매칭 오류 시 수기 매칭으로 전환하는 백업 경로 명시

② 예외 · 분기 처리

flowchart TD
    ACCESS["참가자 웹 재접속"] --> STATE{"참가자 상태 확인"}

    STATE -- "이미 참여 완료" --> DUP["중복 참여 안내 화면
재입력 불가, 기존 제출 내역 안내"]
    STATE -- "제출은 했지만 매칭 전" --> WAIT2["매칭 대기 화면 그대로 노출
(매칭 날짜/시간 재안내)"]
    STATE -- "매칭 결과 공개됨" --> RESULT2["매칭 결과 화면 바로 진입
(대기 화면 건너뜀)"]
    STATE -- "정보 수정 요청" --> EDIT["운영진 문의 → 관리자 페이지에서
참가자 정보 수정 처리"]
    STATE -- "웹 오류 발생" --> ERR["오류 안내 화면"]

    ERR --> ERRTYPE{"오류 범위"}
    ERRTYPE -- "개인 접속 오류" --> RETRY["새로고침 / 재접속 안내"]
    ERRTYPE -- "온라인 매칭 시스템 오류" --> MANUAL2["수기 매칭 전환
(매칭 실패 없이 운영진이 수동 처리)"]
※ 온라인 매칭 시스템에 문제가 생겨도 참가자에게 "매칭 실패"가 노출되지 않도록, 항상 수기 매칭 백업 경로로 흡수한다.
